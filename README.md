# 🔮 Predict Next Number – Πρόβλεψη επόμενου αριθμού ακολουθίας

Ένα απλό πρόγραμμα σε Python που προβλέπει τον επόμενο αριθμό μιας αριθμητικής ακολουθίας, χρησιμοποιώντας **γραμμική παλινδρόμηση** (linear regression). Ιδανικό για φοιτητές πληροφορικής που θέλουν να δουν μια εφαρμογή μηχανικής μάθησης χωρίς βιβλιοθήκες υψηλού επιπέδου.

## 📌 Περιγραφή

Το πρόγραμμα διαβάζει μια λίστα αριθμών από τον χρήστη (π.χ. `2, 4, 6, 8`) και υπολογίζει την ευθεία που ταιριάζει καλύτερα στα σημεία `(θέση, τιμή)`. Στη συνέχεια κάνει πρόβλεψη για την επόμενη θέση. Η μέθοδος είναι γραμμική, οπότε λειτουργεί καλά όταν η ακολουθία ακολουθεί περίπου γραμμική τάση.

## 📦 Απαιτήσεις

- Python 3.6 ή νεότερη
- Βιβλιοθήκη `numpy` (εγκαθίσταται εύκολα)

## 🚀 Εγκατάσταση

1. Κάνε clone ή κατέβασε τα αρχεία του project.
2. Βεβαιώσου ότι έχεις εγκατεστημένη την Python.

## 🚀 Πώς να χρησιμοποιήσεις την εφαρμογή

Ο πιο εύκολος τρόπος είναι να κάνεις διπλό κλικ στα αρχεία αυτόματης εκκίνησης ανάλογα με το σύστημά σου. Αυτά θα ελέγξουν αν υπάρχει η Python, θα εγκαταστήσουν αυτόματα το `numpy` (αν λείπει) και θα ανοίξουν το πρόγραμμα:

- Στα **Windows**: Κάνε διπλό κλικ στο `run.bat` (ή δεξί κλικ -> Run with PowerShell στο `run.ps1`).
- Στα **Linux / macOS**: Τρέξε το `run.sh` από το τερματικό:
  ```bash
  chmod +x run.sh
  ./run.sh
  ```

Εναλλακτικά, αν θέλεις να το τρέξεις χειροκίνητα:
```bash
pip install -r requirements.txt
python predict_next.py
```

## ✨ Νέες δυνατότητες

- Επιλογή μεθόδου: `auto`, `linear`, `quadratic`, `arithmetic`, `geometric`, `fibonacci`
- Αυτόματη ανίχνευση αριθμητικής, γεωμετρικής προόδου ή ακολουθίας Fibonacci
- Έξυπνη επιλογή του καλύτερου μοντέλου με βάση την ποιότητα προσαρμογής
- Υποστήριξη για αριθμούς χωρισμένους με κόμμα ή κενό
- Προβολή επιπλέον λεπτομερειών με `--verbose`
